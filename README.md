| 檔案 | 內容 |
| --- | --- |
| [`index.html`](index.html) | 芯漾生醫 — EC 成效報告 2026 Q1（GA4 ／ Windsor.ai） |

## 說明

- 兩份頁面共用同一套設計系統（色票、字體、卡片／表格元件），可直接互相複製區塊。
- 外部相依：Google Fonts、Chart.js 4.4.1（CDN）。無網路時圖表會顯示提示文字，頁面其餘內容仍可正常閱讀。
- `ai-agent-scope.html` 中的場景數、工時與成效目標為內部盤點階段的估算值，正式數字以 POC 前後量測為準。
